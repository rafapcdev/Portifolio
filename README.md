# Portfólio — Rafael Pereira Costa

Portfólio profissional de Rafael Pereira Costa, desenvolvido para apresentar experiência, formação e projetos nas áreas de desenvolvimento de software, DevOps, cloud, IoT e automação.

Site: [rafaelpc.com.br](https://rafaelpc.com.br/)

## Tecnologias do projeto

- React 19 e Vite
- Tailwind CSS
- Motion
- React Icons

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run build
```
